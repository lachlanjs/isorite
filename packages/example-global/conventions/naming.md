type: Concept
title: Naming
tags: [convention]
description: How things are named, in every base and every project.
---

A name says what a thing is for, not what it is made of. `store.ts` holds the store; `utils.ts` holds whatever nobody could name.

- Files and note ids are lower case words joined by hyphens: `save-by-rename.md`.
- A note's title is a noun phrase, or a question when the note is one.
- A name that needs a comment to explain it is renamed, not commented.
- One name for one thing. When two words are in use, the [glossary](/glossary/base.md "see also") says which wins.
