type: Concept
title: Writing notes
tags: [convention, writing]
description: One idea a note, in your own words, with links that say what they mean.
---

Write one idea a note, with a title that names it and a description that says it in a line. Write in your own words: a note you could not rewrite is one you have not understood yet.

Link as you write, and give each link a kind: `requires` when the idea cannot be read without the other, `uses` when it leans on it, `see also` when it is only near. A link with no kind is a link nobody thought about.

Leave a question open when it is open. A note that pretends to know is worse than a gap, because the gap is visible. See [naming](/conventions/naming.md "see also") for what to call the note.
