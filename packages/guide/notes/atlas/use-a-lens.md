In the Atlas's header, pick Tour. Find the island for the step you are on and read its notes in the order it lists them.

Then pick Islands again: the same notes, grouped by their folders. Name one note that has moved island, and say why.

Now make one of your own. In the Atlas's settings, type a name under new lens, add an island, and give it a rule, `path:/atlas/**`. Put one note from elsewhere in it from the note's menu in the list. Which notes did the rule bring, and which did you?
