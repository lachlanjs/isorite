---
type: Problem
title: Let the agent remember
uses: [terminal/memory]
---

Run `isorite memory`, then `isorite term` in a project of yours. Tell the agent something about how you work that it should remember, and watch it appear in the memory's tab: switch to `memory` from the base's name in the first pane's header.

This needs isorite of your own, not the guide's site: see [starting a base](/your-own-base/starting-a-base.md).
