---
type: Problem
title: Let the agent remember
tags: [agent, memory, practice]
uses: [bases/memory]
---

Run `isorite memory`, then attach your agent to a project's base. Tell it something about how you work that it should remember, and watch it appear in the memory's tab: switch to `memory` from the base's name in the first pane's header.

This needs isorite of your own, not the guide's site: see [starting a base](/bases/starting-a-base.md).
