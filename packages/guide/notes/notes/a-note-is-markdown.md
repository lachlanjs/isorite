---
type: Concept
title: A note is Markdown
description: A note is a Markdown file, written as you read it.
---

Every note is a Markdown file in the base's folder, and the folder is the base: you can open it in any editor, keep it in git, or copy it away. isorite keeps its own records beside the notes, in `.isorite/`.

The Note pane shows Markdown as it reads, and shows its marks only on the line you are writing in:

- `**bold**` and `*italic*`, `# headings`, lists and `> quotes`.
- Maths between dollars, `$E = mc^2$` in a line or `$$…$$` on its own, as $\int_0^1 x\,dx = \tfrac12$.
- Code in backticks, and in fenced blocks, coloured by its language; and [diagrams](/notes/diagrams-and-code.md "see also") written in Mermaid.

There is nothing to save: what you type is kept as you type it, and [every change is kept](/notes/every-change-is-kept.md "see also").

Notes are joined by [links](/notes/links-and-their-kinds.md "see also"), and say what they are in [their details](/notes/a-notes-details.md "see also").
