---

An artifact is an HTML file beside your notes that isorite shows working: a dashboard of a data file, two runs compared, a simulation you can play, a 3D model you can turn. It is a file of the base, on the Atlas with the [files beside the notes](/general/the-switches.md "see also"), and opened in the Note pane. Shown in a note with the picture's syntax, it works in place:

![The guide in numbers](/agents/artifacts/the-guide.html)

Ask your agent in [the Agent pane](/agents/the-agent-pane.md "uses") for one: "a dashboard of runs.csv". It builds it on isorite's kit, which gives it its look. It reaches nothing outside itself: no network, only the data files it names. "Standalone" saves it as one file that opens anywhere.

Its artifacts are checked and run before they are written, and [marked and put back](/editing/every-change-is-kept.md "see also") as its notes are.
