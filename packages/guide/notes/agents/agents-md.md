A file named `AGENTS.md` at the top of the base holds what any agent should know about working in it: your notation, the level you write at, the language, how you name notes. It is a file and not a note, so it is not on the Atlas.

Every agent you attach is given it, with isorite's brief of the base. Edit it in the Agent pane's settings. An agent may offer lines for it when it notices a way of working worth keeping; you choose whether to take them.

This guide has one: it asks the agent to answer from the guide and to point you to the problems. [Let it write](/agents/let-it-write.md "see also") has you write your own.
