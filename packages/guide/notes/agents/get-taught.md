In the Agent pane of an isorite of your own, with the agent set up, type `/socratic-tutor teach me isorite` and answer its questions.

When it has drawn its map of the topic, find the part you rate lowest, and say what in this tour would raise it.

This needs an agent with a model: not the guide's site, whose finder is no tutor. See [starting a base](/bases/starting-a-base.md).
