---

An artifact is an HTML file beside your notes that isorite shows working: a dashboard of a data file, two runs compared, a simulation you can play, an explanation you can change and watch, a 3D model you can turn. It is a file like any other in the base, on the Atlas with the [files beside the notes](/atlas/the-switches.md "see also"), and opened in the Note pane.

Shown in a note, with the picture's syntax, it works in place:

![The guide in numbers](/agent/artifacts/the-guide.html)

Ask your agent in [the Agent pane](/agent/agent.md "uses") for one: "a dashboard of runs.csv", "a simulation of this note's model". It builds it with isorite's tools, on isorite's kit, which gives it its look, so it reads as the rest of isorite does, and the plain look is a press away. It reaches nothing outside itself: no network, only the data files it names. And "standalone" saves it as one file, with its data inside, that opens anywhere.

Its artifacts are checked and run before they are written, and [marked](/agent/agent-writes-marked.md "see also") and put back as its notes are: [every change is kept](/notes/every-change-is-kept.md "see also").
