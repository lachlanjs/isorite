A file named `AGENTS.md` at the top of the base holds what any agent should know about working in it: your notation, the level you write at, the language, how you name notes. It is a file and not a note: it is not on the Atlas.

[Iso](/iso/iso.md "uses") is sent it with every turn, as a row of its own in [the Context view](/iso/what-iso-is-sent.md "see also"), and [the terminal's agent](/terminal/isorite-term.md "see also") is given it too. The name is the one other agents use.

Edit it in Iso's settings. Iso may offer lines for it, when it notices a way of working worth keeping; you choose whether to take them.

This guide has one: it asks Iso to answer from the guide and to point you to the problems.
