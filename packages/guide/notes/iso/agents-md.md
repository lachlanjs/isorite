title: AGENTS.md
description: Your base's instructions, for every agent you attach.
---

A file named `AGENTS.md` at the top of the base holds what any agent should know about working in it: your notation, the level you write at, the language, how you name notes. It is a file and not a note: it is not on the Atlas.

Every agent you attach is given it, with isorite's brief of the base, the first thing it reads. The name is the one other agents use.

Edit it in Iso's settings. An agent may offer lines for it, when it notices a way of working worth keeping; you choose whether to take them.

This guide has one: it asks the agent to answer from the guide and to point you to the problems.
