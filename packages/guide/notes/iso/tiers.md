type: Concept
title: Tiers
description: "How able a model Iso asks: low, mid or max."
---

Iso's header chooses the tier: **low** for quick answers, **mid**, Iso's own default, and **max** for the hardest. Each is a model of your provider's, named in its tooltip, and set in Iso's settings.

The more able, the more each turn costs. The gauge in Iso's header shows what this conversation is sent, and Iso's settings what it has spent this month, against a limit if you set one.

Summing up a conversation is done on the low tier, as it needs no more.

Tiers are [Iso](/iso/iso.md "requires")'s, not the terminal's: its agent uses the model you started it with.
